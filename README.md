# ИИ-ассистент для Telegram, WhatsApp и Instagram

Один шаблон — разные роли и разные мессенджеры. Кем будет бот, решает база
знаний, а где он общается — одна строка в настройках:

| Роль | Для кого | Что делает |
|---|---|---|
| Консультант | клиника, барбершоп, салон, детейлинг, магазин | отвечает про услуги и цены, собирает заявки на запись |
| Куратор | онлайн-школа, курс, наставничество | объясняет материал, напоминает правила, отвечает ученикам |
| Поддержка | сервис, приложение, продукт | решает частые проблемы, сложное отдаёт человеку |

| Канал | Настройка |
|---|---|
| Telegram | 5 минут, работает с компьютера. Нужен всегда — это ещё и панель менеджера |
| WhatsApp | на выбор: **по QR-коду** (Green API) — 10 минут, без сервера, но неофициально; или **официально** (WhatsApp Cloud API) — сервер + аккаунт Meta + отдельный номер |
| Instagram | Instagram API: сервер + аккаунт Meta + профессиональный аккаунт |

Настраивается без программирования: Claude Code сам расспросит тебя о бизнесе,
соберёт базу знаний и проведёт по подключению каналов.
Стартовый промпт — в [START_PROMPT.md](START_PROMPT.md),
подключение WhatsApp и Instagram — в [CHANNELS.md](CHANNELS.md).

## Быстрый старт

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполни .env — SETUP.md; базу знаний — по INTERVIEW.md (проще через Claude Code)
python check_setup.py
python test_bot.py
python bot.py
```

## Что умеет

**Отвечает по базе знаний.** Всё, что бот знает, лежит в папке `knowledge/`
обычными текстовыми файлами. Чего там нет — бот не выдумывает, а честно говорит
и предлагает позвать менеджера.

**Собирает заявки.** Клиент хочет записаться — бот спрашивает имя и телефон
и присылает тебе карточку «📝 Новая заявка». Все заявки — командой `/leads`
в виде таблицы, которая открывается в Excel.

**Выгружает заявки в CRM или таблицу.** Укажи `LEAD_WEBHOOK_URL` — и каждая
заявка улетит JSON-ом в n8n, Make или Zapier, а оттуда в amoCRM, Bitrix24 или
Google Таблицу. Без кода под каждую CRM. Если внешний сервис упал, диалог
с клиентом не страдает.

**Не теряет заявки молча.** Клиент оставил телефон, а ИИ не оформил заявку —
через 10 минут тебе придёт предупреждение с перепиской.

**Отвечает по-человечески.** `REPLY_DELAY_SECONDS` выдерживает паузу перед
ответом, в Telegram с индикатором «печатает…».

**Передаёт диалог человеку.** Клиент жалуется, просит менеджера, задаёт
нестандартный вопрос, нажимает «👤 Позвать человека» (Telegram) или пишет
«менеджер» (WhatsApp, Instagram) — тебе в Telegram приходит карточка
с последними сообщениями. Ты отвечаешь на неё через **Reply**, и ответ уходит
клиенту туда, откуда он пришёл. Пока ты на связи, ИИ молчит.
Кнопка «🤖 Вернуть клиента ИИ» — включить его обратно (или он вернётся сам
через `HUMAN_TIMEOUT_HOURS` часов).

**Все каналы — в одном месте.** Заявки и вопросы из Telegram, WhatsApp и
Instagram приходят в один Telegram-чат, с пометкой канала. Фото и голосовые
из WhatsApp бот пересылает менеджеру файлом.

**Не ломается молча.** Нейросеть не ответила — клиент получает извинение,
а его вопрос уходит тебе. Любая другая ошибка — тебе приходят подробности.
При запуске бот присылает отчёт: база знаний и статус каждого канала.

**Любая нейросеть одной строкой.** `LLM_PROVIDER=deepseek` — самая дешёвая,
`anthropic` — строже соблюдает правила, плюс `gemini`, `openai`, `openrouter`.
Поменять — одно слово в `.env`.

**Проверяется до запуска.** `python test_bot.py` задаёт боту вопросы клиентов и
ловит, где он выдумал ответ, не оформил заявку или не позвал менеджера.
Тот же набор на другой модели — и видно, какую брать.

**Бережёт бюджет.** Лимит вопросов в сутки на одного клиента (`DAILY_LIMIT`).

## Команды админа

| Команда | Что делает |
|---|---|
| `/admin` | список команд и как отвечать клиентам |
| `/reload` | перечитать базу знаний после правок — без перезапуска |
| `/stats` | клиенты, вопросы, заявки |
| `/leads` | все заявки файлом |
| `/reset` | сбросить свой диалог — для тестов |

Пиши боту сам как обычный клиент — так проще всего проверять ответы.
Лимит вопросов на админов не действует.

## Ограничения — честно

- **WhatsApp по QR-коду — неофициальный способ.** Подключается за минуты, но WhatsApp
  может заблокировать номер. Официальный путь через Meta надёжен, но требует сервер,
  аккаунт Meta и время. Сравнение и риски — CHANNELS.md.
- **Официальный WhatsApp — отдельный номер.** Номер, который сейчас работает в приложении
  WhatsApp, через Meta без дополнительной настройки (режим сосуществования через
  партнёров) подключить нельзя. По QR-коду — можно.
- **Окно 24 часа.** В WhatsApp и Instagram ответить клиенту можно в течение
  суток после его последнего сообщения. Бот предупреждает менеджера, если окно закрылось.
- **WhatsApp платный за каждый ответ.** С 1 октября 2026 года Meta берёт плату
  за каждое сообщение бизнеса клиенту, включая ответы бота. Цена зависит от страны
  клиента — заложи её в абонентку (CHANNELS.md → «Правило 24 часов и цены»).
- **Только текст.** Голосовые и фото ИИ не понимает: в обычном режиме просит
  написать текстом, а в режиме менеджера пересылает их менеджеру.
- **Менеджер отвечает в WhatsApp и Instagram только текстом.**
- **База читается целиком.** Отлично до ~60 000 символов (примерно 30 страниц).
  Больше — ответы дороже и медленнее; тогда нужен поиск по базе.
- **Запись не встроена в календарь.** Бот собирает заявку, а записывает человек.
  Интеграцию с календарём или CRM можно добавить отдельно.

## Безопасность

- `.env` и `assistant.db` не попадают в git. В `.env` — токены и ключ нейросети,
  в базе — переписки клиентов.
- Сообщения от WhatsApp и Instagram бот принимает только с правильной подписью
  Meta — поддельные запросы отбрасываются.
- Команды админа и кнопки работают только для id из `ADMIN_ID`.
- Ключ нейросети = деньги. Поставь лимит расходов в кабинете провайдера.
- Переписка клиентов уходит провайдеру нейросети. Для чувствительных данных
  (медицина и т.п.) выбирай провайдера осознанно и обсуди это с владельцем бизнеса.
