# Каналы: Telegram, WhatsApp, Instagram

Этот файл — пошаговая инструкция для подключения каналов. По нему Claude Code
объясняет владельцу, где что нажать и откуда взять каждое значение.

> **Для Claude Code.** Кабинеты Meta часто меняются: кнопки переезжают и
> переименовываются. Если у человека экран не совпадает с описанием — попроси
> скриншот и веди по тому, что видно на нём. Не выдумывай пункты меню.

---

## Как это устроено

```
Клиент в Telegram  ─┐
Клиент в WhatsApp  ─┼─►  бот (база знаний + ИИ)  ─►  менеджер в Telegram
Клиент в Instagram ─┘                                 (заявки, ответы через Reply)
```

- **Где пишут клиенты** и **где работает менеджер** — два разных вопроса.
  Клиенты: любой набор из Telegram, WhatsApp, Instagram, в том числе только
  WhatsApp. Менеджер: всегда Telegram-бот — это его панель. Ответ менеджера
  уходит клиенту в тот мессенджер, откуда клиент пришёл.
- **Почему панель не в WhatsApp.** По правилам Meta бот не может сам написать
  в WhatsApp тому, кто молчал больше 24 часов, без платного шаблона. Уведомление
  о ночной заявке просто не дошло бы до менеджера. В Telegram таких ограничений нет.
- Какие каналы открыты для клиентов, решает строка `CHANNELS` в `.env`:
  ```
  CHANNELS=whatsapp                     # клиенты только в WhatsApp
  CHANNELS=whatsapp,instagram           # WhatsApp и Instagram
  CHANNELS=telegram,whatsapp,instagram  # все три
  ```
  Если `telegram` в списке нет, бот в Telegram отвечает клиентам «напишите нам
  в WhatsApp», а для админов работает как обычно. Админы могут сами переписываться
  с ИИ — удобно для тестов.

## WhatsApp: два способа подключения

| | По QR-коду (Green API) | Официально (Meta) |
|---|---|---|
| Настройка | 5–10 минут | от вечера до пары недель |
| Сервер | не нужен, работает с ноутбука | нужен, с https-адресом |
| Номер | любой, в том числе текущий номер бизнеса | отдельный номер (или сосуществование через партнёра Meta) |
| Ответ с телефона | видно: бот сам замолкает в этом чате | не видно |
| Окно 24 часа | нет | есть |
| Цена | подписка Green API за номер | плата Meta за каждый ответ |
| **Риск** | **неофициально: WhatsApp может заблокировать номер** | нет |

Строка в `.env`: `WHATSAPP_VIA=greenapi` или `WHATSAPP_VIA=meta`.

**Для учёбы, демо клиенту и первых проектов** — QR-код. **Для бизнеса, где потеря номера
критична** (клиника, у которой все пациенты пишут на этот номер) — официально через Meta.
Решение за владельцем номера, и он должен знать о риске.

## Честно о сроках

| Канал | Что нужно | Сколько времени |
|---|---|---|
| Telegram | токен у @BotFather | 5 минут, работает с ноутбука |
| WhatsApp по QR-коду | аккаунт Green API | 10 минут, работает с ноутбука |
| WhatsApp официально | сервер + аккаунт Meta + отдельный номер | тестовый номер — за вечер; свой номер — от дня до пары недель (проверки Meta) |
| Instagram | сервер + аккаунт Meta + профессиональный аккаунт Instagram | за вечер для своего аккаунта; для чужих — проверка Meta |

## Правильный порядок

1. Настроить и проверить всё в Telegram: база знаний, ответы, заявки.
   **Мозг бота один на все каналы** — если он хорошо отвечает в Telegram,
   так же он ответит в WhatsApp.
2. Поставить бота на сервер с https-адресом (раздел «Сервер»).
3. Подключать WhatsApp и Instagram по одному.

## Сервер

WhatsApp и Instagram сами присылают сообщения на адрес бота. Поэтому бот
должен жить на сервере с адресом вида `https://...`. С ноутбука это не работает.

### Вариант А. Railway (проще всего)

1. Залить папку проекта в приватный репозиторий на GitHub
   (Claude Code сделает это с твоего разрешения; `.env` и база туда не попадут).
2. На railway.com → New Project → Deploy from GitHub → выбрать репозиторий.
3. **Variables:** перенести туда все строки из `.env`. На сервере файла `.env`
   нет — настройки живут здесь.
4. **Volume:** добавить диск, путь монтирования `/data`, и в Variables добавить
   `DB_PATH=/data/assistant.db`. Без этого база с заявками и историей
   стирается при каждом обновлении.
5. **Networking → Generate Domain** — получишь адрес вида
   `https://имя.up.railway.app`. Впиши его в Variables как `PUBLIC_URL`.
6. Команда запуска: `python bot.py` (в проекте есть `Procfile`).

> Важно: на сервере база знаний берётся из репозитория. Поправил файл в
> `knowledge/` — нужно отправить изменения на GitHub, Railway обновит бота сам.
> `/reload` на сервере перечитывает только то, что уже залито.

Тарифы Railway меняются — актуальные смотри на сайте.

### Вариант Б. Свой VPS

Самый дешёвый VPS + домен. Попроси Claude Code: «настрой бота на сервере через
systemd и Caddy для https» и дай доступ к серверу. Если на сервере уже есть n8n —
можно поставить рядом.

### Для теста без сервера: временный туннель

Пока бот запущен на ноутбуке, можно дать ему временный https-адрес:

```bash
cloudflared tunnel --url http://localhost:8080
```

Он покажет адрес вида `https://....trycloudflare.com` — вписать в `PUBLIC_URL`
и использовать в настройках вебхука. Адрес меняется при каждом запуске,
поэтому только для проверки.

### Что вставлять в Meta

Запусти `python check_setup.py` — в конце он напечатает готовые значения:

```
WhatsApp  Callback URL:  https://твой-адрес/webhook/whatsapp
Instagram Callback URL:  https://твой-адрес/webhook/instagram
Verify token:            a1b2c3...
```

Verify token — это пароль, по которому Meta проверяет, что адрес твой.
Бот придумывает его сам. Если хочешь свой — задай `META_VERIFY_TOKEN` в `.env`.

## WhatsApp через QR-код (Green API)

Номер подключается к боту как «связанное устройство» — так же, как WhatsApp Web
на компьютере. Бот сам забирает новые сообщения, поэтому ни сервер, ни Meta не нужны.

### Что понадобится в .env

```
CHANNELS=whatsapp            # или telegram,whatsapp
WHATSAPP_VIA=greenapi
GREENAPI_ID_INSTANCE=        # idInstance
GREENAPI_API_TOKEN=          # apiTokenInstance
GREENAPI_API_URL=            # apiUrl
```

### Шаг 1. Аккаунт и инстанс

1. Зарегистрируйся на green-api.com → личный кабинет (console.green-api.com).
2. **Создать инстанс.** Для проверки хватит бесплатного тарифа **Developer**, но он
   работает только с 3 чатами. Для настоящих клиентов нужен платный тариф —
   он оплачивается за каждый номер отдельно. Цены — на сайте Green API.
3. В карточке инстанса скопируй три значения: **idInstance**, **apiTokenInstance**,
   **apiUrl** — в `.env`.
4. Поле **Webhook URL** у инстанса оставь **пустым**. Если там что-то есть, бот не сможет
   забирать сообщения (он сам скажет об этом в логах).

### Шаг 2. Привязать номер

Запусти бота (`python bot.py`). В отчёте «Бот запущен» в Telegram и по команде
`/whatsapp` будет ссылка вида `http://localhost:8080/connect/...`.

- **Свой номер:** открой ссылку в браузере на том же компьютере. Покажется QR-код —
  на телефоне WhatsApp → Настройки → **Связанные устройства** → Привязка устройства →
  наведи камеру. Или введи номер и получи код для входа по номеру телефона.
- **Номер клиента:** когда бот на сервере (`PUBLIC_URL` задан), ссылка из `/whatsapp`
  открывается откуда угодно. Отправь её владельцу номера — он сам отсканирует QR
  со своего телефона. Доступ к боту и кабинетам ему не нужен. Ссылку никому
  больше не показывай: по ней можно привязать номер к твоему боту.

Можно и проще: QR-код есть в самом кабинете Green API.

### Шаг 3. Выключить автоответы

Если на номере стоит WhatsApp Business с **приветствием** или **«нет на месте»** —
выключи их. Они уходят с твоего номера, бот решит, что ответил менеджер, и замолчит
в этом чате.

### Как работает ответ с телефона

Ты или администратор ответили клиенту прямо с телефона — бот это видит, замолкает
в этом чате и присылает в Telegram «📱 Ты ответил клиенту с телефона». Вернуть бота —
кнопкой «Вернуть клиента ИИ» (или сам через `HUMAN_TIMEOUT_HOURS`). Выключить такое
поведение — `WHATSAPP_PAUSE_ON_PHONE_REPLY=0`.

### Риски — читать обязательно

Green API и подобные сервисы подключаются к WhatsApp в обход официального API.
Это против правил WhatsApp, и номер **могут заблокировать** — вместе с перепиской.
Как снизить риск:

- Бот только **отвечает** на входящие — не используй номер для рассылок и
  холодных сообщений. Шаблон сам первым не пишет.
- Включи паузу «печатает» `REPLY_DELAY_SECONDS=5`–`8` — мгновенные ответы
  выглядят как робот.
- Лучше «живой» номер, которым давно пользуются, а не только что купленная SIM.
- Если номер отключился — бот напишет «⚠️ WhatsApp отключился». Привяжи заново по `/whatsapp`.

### Если не работает

| Что видишь | В чём дело |
|---|---|
| «неверный GREENAPI_ID_INSTANCE или GREENAPI_API_TOKEN» | скопируй значения из кабинета заново |
| «номер НЕ привязан» | открой ссылку из `/whatsapp` и отсканируй QR |
| В логах про Webhook URL | очисти поле Webhook URL у инстанса в кабинете |
| Отвечает только трём людям | бесплатный тариф Developer — только 3 чата |
| Бот замолчал в чате | кто-то ответил с телефона или сработал автоответ WhatsApp Business |

## Аккаунт Meta (общий для официального WhatsApp и Instagram)

1. **Бизнес-портфолио:** business.facebook.com — войти через свой Facebook и
   создать бизнес-портфолио (название бизнеса, имя, рабочая почта).
2. **Аккаунт разработчика:** developers.facebook.com — войти тем же Facebook,
   принять условия и подтвердить телефон, если попросит.
3. **Приложение:** developers.facebook.com → My Apps → Create App.
   - Назначение (use case): для WhatsApp — пункт про общение с клиентами в WhatsApp;
     если нужен и Instagram — пункт «Other / Другое».
   - Тип приложения: **Business**.
   - Привязать к своему бизнес-портфолио.

   Одно приложение может обслуживать и WhatsApp, и Instagram.

4. **Секрет приложения:** App settings → Basic → App Secret → Show.
   Он нужен, чтобы бот отличал настоящие сообщения от Meta от поддельных.

## WhatsApp официально (Meta)

### Что понадобится в .env

```
CHANNELS=telegram,whatsapp
WHATSAPP_VIA=meta
WHATSAPP_TOKEN=               # постоянный токен (шаг 5)
WHATSAPP_PHONE_NUMBER_ID=     # ID номера — НЕ сам номер (шаг 1)
WHATSAPP_BUSINESS_ACCOUNT_ID= # ID WhatsApp-аккаунта (шаг 1)
WHATSAPP_APP_SECRET=          # App Secret из App settings → Basic
```

### Шаг 1. Добавить WhatsApp в приложение

В приложении: Add product → WhatsApp → Set up. Откроется страница
**WhatsApp → API Setup**. На ней есть:

- тестовый номер от Meta,
- **Phone number ID** → `WHATSAPP_PHONE_NUMBER_ID`,
- **WhatsApp Business Account ID** → `WHATSAPP_BUSINESS_ACCOUNT_ID`,
- временный токен (живёт около суток) — для первой проверки можно вписать
  его в `WHATSAPP_TOKEN`.

### Шаг 2. Проверить на тестовом номере

1. На той же странице в поле «To» добавь свой личный номер WhatsApp и подтверди
   его кодом. Тестовый номер пишет только номерам из этого списка (до 5 штук).
2. Webhook: **WhatsApp → Configuration → Webhook → Edit**:
   - Callback URL — из `check_setup.py`,
   - Verify token — из `check_setup.py`,
   - Verify and save. **Бот в этот момент должен быть запущен**, иначе Meta
     не достучится.
3. Там же, в **Webhook fields**, подпиши поле **messages**.
4. Напиши с личного WhatsApp на тестовый номер — бот должен ответить.

### Шаг 3. Свой номер

- Нужен номер, который **не используется в приложении WhatsApp**. Самое простое —
  новая SIM-карта. Если хочешь оставить рабочий номер клиники в приложении
  WhatsApp Business и одновременно подключить бота, у Meta есть режим
  сосуществования (coexistence). Он подключается через Embedded Signup,
  обычно через официальных партнёров Meta, и в этот шаблон не входит.
- API Setup → Add phone number: отображаемое имя бизнеса (его проверяет Meta),
  номер, код по SMS или звонком.
- Новый **Phone number ID** — в `WHATSAPP_PHONE_NUMBER_ID`.
- Если номер висит в статусе «ожидает» и не отправляет сообщения, его нужно
  зарегистрировать с 6-значным PIN. Claude Code сделает это одной командой.

### Шаг 4. Перевести приложение в рабочий режим

В верхней части страницы приложения есть переключатель **App Mode:
Development → Live**. Для него нужна ссылка на политику конфиденциальности
(App settings → Basic → Privacy Policy URL). Если её нет — Claude Code сделает
простую страницу. Если сообщения от обычных клиентов не приходят, первым делом
проверь этот переключатель.

Для больших объёмов и некоторых функций Meta может попросить подтвердить
бизнес (Business Verification) — это документы и ожидание.

### Шаг 5. Постоянный токен

Временный токен живёт около суток. Для работы нужен постоянный:

1. business.facebook.com → **Settings / Настройки компании → Users →
   System users** → Add: имя `bot`, роль **Admin**.
2. У этого пользователя: **Assign assets** → приложение (полный доступ) и
   WhatsApp-аккаунт (полный доступ).
3. **Generate token** → выбрать приложение → срок: **Never / Бессрочно** →
   разрешения `whatsapp_business_messaging` и `whatsapp_business_management`.
4. Скопировать токен в `WHATSAPP_TOKEN`. Meta покажет его один раз.

### Правило 24 часов и цены

Ответить клиенту обычным сообщением можно в течение 24 часов после его последнего
сообщения. Позже Meta разрешает писать только заранее одобренными шаблонами.
Бот это учитывает: если менеджер отвечает позже, бот не отправит сообщение и скажет
связаться с клиентом по телефону.

**С 1 октября 2026 года Meta берёт плату за каждый ответ бизнеса в WhatsApp**, в том
числе за ответы ИИ-бота внутри окна 24 часа. Раньше они были бесплатными. Цена за
сообщение зависит от страны клиента и равна тарифу utility-шаблонов этой страны.
Сообщения клиентов боту бесплатны. Разговоры, начатые с рекламы Click-to-WhatsApp,
бесплатны 72 часа.

Как это учитывать:

- Бот отправляет один ответ на одно сообщение клиента. Не дроби ответы
  на несколько сообщений — каждое оплачивается отдельно.
- Закладывай стоимость сообщений в абонентскую плату клиента: сколько сообщений
  в месяц × тариф страны. Актуальные тарифы — в rate card Meta
  (developers.facebook.com → WhatsApp → Pricing). Тарифы меняются до 4 раз в год.
- Сообщения в **Instagram** Meta не тарифицирует.

### Если не работает

| Что видишь | В чём дело |
|---|---|
| Meta пишет, что не может проверить Callback URL | бот не запущен, неверный адрес или verify token |
| В логах «подпись запроса не совпала» | в `WHATSAPP_APP_SECRET` не тот секрет |
| «номера нет в списке разрешённых» | тестовый номер пишет только номерам из списка «To» |
| «токен доступа недействителен» | истёк временный токен — сделай постоянный (шаг 5) |
| Свои сообщения доходят, клиентские — нет | приложение в режиме Development (шаг 4) |
| Бот не отвечает на голосовые | он понимает только текст, голосовые уходят менеджеру |

## Instagram

Используется **Instagram API with Instagram Login**: Facebook-страница не нужна.

### Что понадобится в .env

```
CHANNELS=telegram,instagram
INSTAGRAM_TOKEN=        # токен из кабинета (шаг 3)
INSTAGRAM_APP_SECRET=   # секрет (шаг 4)
```

### Шаг 1. Подготовить аккаунт Instagram

1. Аккаунт должен быть **профессиональным** (Бизнес или Автор), не личным:
   Instagram → Настройки → Тип аккаунта и инструменты → Переключиться на
   профессиональный аккаунт.
2. Разрешить доступ к сообщениям: Instagram → Настройки → Сообщения и ответы
   на истории → Управление сообщениями → **Разрешить доступ к сообщениям**
   (в разделе подключённых инструментов). Без этого бот не увидит сообщения.

### Шаг 2. Добавить Instagram в приложение

В приложении Meta: Add product → **Instagram** → Set up.
Выбрать **API setup with Instagram login**. Вариант «with Facebook login» —
другой способ, шаблон его не поддерживает.

### Шаг 3. Токен

На странице **Instagram → API setup with Instagram login**:

1. **Generate access tokens → Add account** — войти в Instagram-аккаунт бизнеса.
2. Нажать **Generate token** напротив аккаунта, снова войти, скопировать токен
   в `INSTAGRAM_TOKEN`.

Токен живёт 60 дней. **Бот сам продлевает его раз в неделю**, менять `.env`
не нужно. Если бот был выключен больше 60 дней — сгенерируй токен заново.
Если продлить не получится, бот напишет админам в Telegram.

### Шаг 4. Секрет для проверки подписи

На той же странице, в блоке настройки входа через Instagram (обычно шаг 3),
есть **Instagram app secret** — впиши его в `INSTAGRAM_APP_SECRET`.

Если после настройки в логах бота появится «Instagram: подпись запроса не
совпала», попробуй вместо него **App Secret** из App settings → Basic.

### Шаг 5. Вебхук

На странице **API setup with Instagram login → Configure webhooks**:

1. Callback URL и Verify token — из `check_setup.py`. Бот должен быть запущен.
2. Verify and save.
3. В списке полей подписать **messages**.

Подписку самого аккаунта на сообщения бот делает сам при запуске — в отчёте
«Бот запущен» будет строка «Instagram: @аккаунт · подписка на сообщения активна».

### Шаг 6. Рабочий режим

Переключи приложение в **Live** (как в шаге 4 WhatsApp). Пока оно в режиме
разработки, Meta присылает сообщения только от людей с ролью в приложении —
обычные клиенты до бота не дойдут.

### Свой аккаунт или аккаунт клиента

- Свой аккаунт или аккаунт, которым ты управляешь и который добавлен в
  приложение, работает на стандартном доступе без проверки Meta.
- Чужие аккаунты (подключение произвольных бизнесов) требуют проверки бизнеса
  и App Review на расширенный доступ. Для внедрения под конкретного клиента
  проще, чтобы владелец аккаунта сам вошёл на шаге 3.

### Правила Instagram

- Ответить можно в течение 24 часов после последнего сообщения клиента.
  Бот проверяет это перед ответом менеджера.
- Одно сообщение — до 1000 байт (примерно 500 букв кириллицей). Длинные ответы
  бот сам режет на несколько сообщений.
- Новые диалоги от тех, кто не подписан на аккаунт, попадают в «Запросы».
  Бот их видит и отвечает.

### Если не работает

| Что видишь | В чём дело |
|---|---|
| Сообщения не приходят вообще | не включён «Разрешить доступ к сообщениям» (шаг 1) или не подписано поле messages (шаг 5) |
| Приходят только твои сообщения | приложение в режиме Development (шаг 6) |
| «подпись запроса не совпала» | попробуй второй секрет (шаг 4) |
| «токен доступа недействителен» | токен истёк — сгенерируй заново (шаг 3) |
| Аккаунт не добавляется | аккаунт личный, а нужен профессиональный (шаг 1) |
